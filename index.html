Bridging the Perception Gap in Semantic Video Search

Operators expected semantic search to work like an LLM: type anything, get relevant results. But crop-frame search only catches objects attached to or near a person, so queries silently failed. I designed a system of in-context nudges that surfaces how the AI is interpreting each query, before, during, and after the search.
